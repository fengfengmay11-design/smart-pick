## 1. 先搞清楚哪些接口要权限

这是最容易踩坑的地方。京东联盟的接口分两档：

| 接口 | 能干什么 | 权限 |
|------|---------|------|
| `goods.jingfen.query` | 拉京粉精选商品池 | **免申请** |
| `goods.material.query` | 猜你喜欢商品推荐 | **免申请** |
| `category.goods.get` | 商品类目查询 | **免申请** |
| `goods.query` | **按关键词/skuId 搜商品** | 需申请 |
| `goods.bigfield.query` | 商品图文详情 | 需申请 |

**关键点**：免权限的三个接口**都不能搜指定型号**——它们只能按「频道 ID」拉京东推荐的商品池，你没法用它们找到「iPad Pro 13 M4」的价格。

要给自己的 659 款产品刷价，**必须拿到 `goods.query` 权限**。

免权限接口的唯一用处：注册当天先验证签名链路通不通，别等申请下来才发现代码有 bug。

## 2. 注册与实名

1. 打开 <https://union.jd.com/> ，用京东商城账号直接登录（不用另外注册）
2. 首次登录会让你选身份：**个人** / 企业。个人即可，做这个项目够用
3. 进入「账户管理」→ 完成**实名认证**（身份证 + 银行卡）

> 实名认证是硬门槛。不认证的话 appkey 能拿到，但调接口一律返回无权限。

## 3. 创建推广位拿 appkey

路径：**我的推广 → 推广管理 → 网站管理 → 创建网站**

填写要点：

| 字段 | 填什么 |
|------|--------|
| 网站名称 | 智选 SmartPick |
| 网站地址 | 你的 GitHub Pages 地址，如 `https://fengfengmay11-design.github.io/smart-pick/` |
| 网站类型 | 导购/工具类 |
| 网站简介 | 消费电子产品参数对比与选购决策工具，覆盖手机/平板/相机等 13 个品类共 659 款产品，为用户提供横向参数对比 |

**GitHub Pages 域名是可以用的**，不需要备案（备案是国内服务器的要求）。

创建完成后点「**查看**」，你会看到：

- `appkey` —— 填进 `JD_APP_KEY`
- `secretkey` —— 填进 `JD_APP_SECRET`
- `网站ID` —— 即 siteID，填进 `JD_SITE_ID`（选填，转链才需要）

> 注意：网站类型和 APP 类型的 appkey **不通用**。转链接口必须用对应类型的 key。

## 4. 申请 goods.query 权限

**申请入口**：<https://union.jd.com/openplatform/groupApply>

这里有个反直觉的设计：**权限不是逐个接口申请的，而是「选一种推广模式」，审批通过后该模式对应的一整组接口自动开通。**

四种推广模式，选哪个：

| 模式 | 场景 | 适合你吗 |
|------|------|---------|
| 工具商类 | 帮其他推客转链 | ✗ |
| **导购类** | 媒体在自有站点/APP 推广，佣金结算给自己 | **✓ 选这个** |
| 社群代理/返利 | 在第三方平台推广，需要短链 | ✗ |
| 内容流量渠道 | 自有创作平台，与推客分成 | ✗ |

**申请表填写建议**（写清楚用途能显著提高通过率）：

> 本站为消费电子产品参数对比工具（智选 SmartPick），已收录手机、平板、相机、电视、
> 智能手表等 13 个品类共 659 款产品的规格参数。接入商品查询接口用于：
> 1）展示各型号的京东实时价格，替代当前的静态估算价；
> 2）获取商品主图，提升产品展示质量；
> 3）用户点击「去购买」时跳转京东商品页完成转化。
> 站点地址：https://fengfengmay11-design.github.io/smart-pick/

审批周期一般 **1-3 个工作日**。

**常见驳回原因**：

- 网站无实质内容 / 打不开 → 先确保 GitHub Pages 能正常访问
- 用途描述太笼统（如只写「做电商项目」）→ 写清具体场景
- 网站与申请场景不符 → 导购类就要有商品展示页面

你的项目本身就是标准的导购场景，通过率不用太担心。

## 5. 配置到项目里

```bash
cd phone-compare
cp server/.env.example server/.env
```

编辑 `server/.env`，填入：

```ini
JD_APP_KEY=你的appkey
JD_APP_SECRET=你的secretkey
JD_SITE_ID=你的网站ID
```

然后自检：

```bash
python server/verify_setup.py
```

这个脚本会依次检查：`.env` 是否被 git 忽略 → 凭据格式是否正常 → 实际调接口探测每个权限 → 告诉你现在能做什么、还差什么。

输出示例：

```
✓ .env 已被 .gitignore 忽略（key 不会进版本库）
✓ JD_APP_KEY 已配置（ff1c4e…4c31，共 32 位）
✓ [免权限] 京粉精选商品池          返回 1 条数据
✓ [免权限] 猜你喜欢商品推荐        返回 1 条数据
✗ [需申请] 关键词/SKU 搜索商品     无权限，需在联盟后台申请

✓ 签名链路已打通（3/3 个免权限接口可用）
! 关键词搜索（goods.query）暂无权限
```

看到「签名链路已打通」就说明代码和凭据都没问题，剩下的只是等审批。

## 6. 跑起来

### 第一步：小范围试跑

```bash
python server/refresh_prices.py --dry-run --limit 5
```

`--dry-run` 只打印差异不写文件，`--limit 5` 每个品类只试 5 款。先确认匹配质量。

输出长这样：

```
平板  data-tablet.js  共 24 款
  [  1/ 5]   ipad-pro-13-m4          ¥8999 → ¥8499 (-5.6%)
  [  2/ 5] ⚠ ipad-air-13-m2          ¥6799 → ¥5299 (-22.1%)
  [  3/ 5] = xiaomi-pad-7            ¥1999
  [  4/ 5] ⚠ matepad-pro-13          ¥4999 → ¥899 (-82%) 疑似匹配错误，跳过
```

注意第 4 行——关键词搜索会搜到保护壳、贴膜这类配件。脚本内置了保护：跌幅超过 60% 自动跳过（阈值可用 `--max-drop` 调）。

### 第二步：单个品类

```bash
python server/refresh_prices.py --only data-tablet.js
```

写入前会自动备份成 `data-tablet.js.bak.<时间戳>`，写入后立刻用 `node --check` 校验语法，**语法坏了会自动回滚**。

### 第三步：全量

```bash
python server/refresh_prices.py
```

659 款 × 0.3 秒间隔 ≈ 3.5 分钟。基础权限 QPS 限 5 次/秒，0.3 秒间隔留了充足余量。

### 提高匹配精度：给产品补 skuId

关键词搜索难免出错。最准的做法是给产品补 `skuId` 字段：

```json
{
  "id": "ipad-pro-13-m4",
  "brand": "苹果",
  "model": "iPad Pro 13 (M4)",
  "skuId": "100065474274",
  ...
}
```

skuId 就是京东商品页 URL 里的那串数字：`https://item.jd.com/100065474274.html`

有 skuId 时脚本会走精确查询，不再依赖关键词猜测。手工补 659 个成本太高，建议只给热门机型补——它们的展示权重最高。

## 7. 安全须知（必读）

京东联盟帮助中心原话：

> 请妥善保管 appkey 和 secretkey，不要泄露给其他用户，**也禁止保存在任何版本库托管服务（如 GitHub）或以其他途径公开，否则可能被禁用**。

本项目已经做了防护：

- `.gitignore` 已包含 `server/.env`
- 仓库里只有 `.env.example`（占位符，无真实凭据）
- `verify_setup.py` 每次运行都会检查 `.env` 是否被 git 追踪，追踪了会红字告警

**你要做的**：凭据填进 `server/.env`，**不要**填进 `.env.example`。

万一不小心提交了：

```bash
git rm --cached server/.env
git commit -m "chore: remove leaked env"
# 然后立刻去联盟后台重置 secretkey——已推送的历史提交仍能翻出旧 key
```

另外，搜「京东商品 API」会跳出一堆按调用次数收费的第三方代理服务商。那些是中间商，官方渠道是 `union.jd.com`，一分钱不用花。

## 8. 排错手册

| 现象 | 原因 | 解法 |
|------|------|------|
| 免权限接口也全失败 | 凭据错 / 未实名 | 检查 key 有无多余空格；确认实名认证已通过 |
| `invalid signature` | 签名不对 | 多半是 key 复制时带了换行符，重新复制 |
| 时间戳相关错误 | 本机时间偏差 | 京东要求时差 <10 分钟，校准系统时间 |
| `isv.permission-deny` | 没权限 | 去 groupApply 申请导购类推广模式 |
| 调用频繁被限流 | QPS 超了 | 加大 `--delay`，基础权限限 5 次/秒 |
| 价格刷成了配件价 | 关键词匹配错 | 调低 `--max-drop`，或给该产品补 skuId |
| 用的宙斯/商家平台 key | 平台不通用 | 必须用 union.jd.com 的联盟 key |

调试单个接口：

```bash
python server/jd_client.py probe                 # 看权限全貌
python server/jd_client.py jingfen 22            # 免权限接口试水
python server/jd_client.py search "iPad Pro"     # 关键词搜索
python server/jd_client.py refresh 苹果 "iPad Pro 13 (M4)"
```

验证写回逻辑（不需要 API Key）：

```bash
python server/refresh_prices.py --self-test
```
